# اجرای پروژه

ابتدا وابستگی‌های پروژه را نصب کنید:

```bash
npm i
```

سپس سرویس MongoDB را اجرا کنید:

```bash
sudo systemctl start mongod
```

در نهایت پروژه را در حالت Development اجرا کنید:

```bash
npm run dev
```

## ترتیب اجرای دستورات

```bash
npm i
sudo systemctl start mongod
npm run dev
```
